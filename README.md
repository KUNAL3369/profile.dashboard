# Assignment 27: Figma Design Recreation

This project is a recreation of a specific Figma design using React and Next.js. It features a dark-themed UI with a two-column layout: the left half is empty, and the right half contains two interactive widgets - a Profile Tabs widget and a Gallery widget.

## Project Overview

- **Framework**: Next.js with TypeScript
- **Styling**: Tailwind CSS
- **Features**:
  - Responsive design optimized for laptop screens (>768px width)
  - Interactive tabs in the Profile widget (About Me, Experiences, Recommended)
  - Gallery widget with Add Image button and navigation arrows
  - Exact replication of Figma design elements including colors, shadows, padding, and interactions

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build and Deploy

To build the project for production:

```bash
npm run build
```

The easiest way to deploy is using Vercel:

```bash
npx vercel --prod
```
